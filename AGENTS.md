# Правила проекта

Эталонная локаль - Ru

Перед работой открой [карту проекта](PROJECT_MAP.md) и начни с файлов, указанных для текущей задачи. Обновляй карту, если меняешь расположение или назначение файлов.

При выпуске новой версии русификатора отправь исходники соответствующей версии в GitHub и опубликуй версию в GitHub Releases репозитория [sanossan/PC-Store-Together-RUS](https://github.com/sanossan/PC-Store-Together-RUS). Приложи установщик EXE, ZIP-архив, контрольные суммы SHA-256 для обоих файлов и список изменений на русском. Проверь, что опубликованные файлы совпадают с локальной сборкой.

## Правила выпуска

- Повышай третий компонент версии для исправлений перевода и установщика в пределах одной Steam-сборки, например `1.0.0 → 1.0.1`.
- Повышай второй компонент версии для поддержки новой Steam-сборки или перевода нового раздела игры, например `1.0.1 → 1.1.0`.
- Повышай первый компонент версии, если для перехода на новый выпуск игроку требуется сначала восстановить оригиналы, например `1.1.0 → 2.0.0`.
- Выпускай EXE и ZIP для одной проверенной Steam-сборки. Используй `release.json` как источник номера версии и Steam Build ID. Сохраняй историю хешей предыдущих выпусков в пределах этой сборки.
- Собирай пакеты через `installer/Build-Release.ps1` из копии игры с оригинальными файлами. Перед выпуском проверяй обновление, восстановление и контрольные суммы обоих пакетов. Указывай сборку Steam, изменения и порядок обновления в описании релиза.

### История обновлений в README

- При каждом выпуске добавляй запись в начало раскрываемого блока «История обновлений» в [`README.md`](README.md). Сохраняй старые записи в порядке от новых к старым и оставляй блок свёрнутым по умолчанию.
- Бери номер из `release.json` и показывай его с префиксом `v` отдельной жирной строкой. На следующей строке кратко опиши изменения на русском. Укажи новую Steam-сборку или особый порядок обновления, если они изменились.
- Оформляй каждую запись отдельным HTML-абзацем внутри `<details>`, чтобы номер и описание отображались на разных строках.

```html
<p>
<strong>vX.Y.Z</strong><br />
Описание изменений.
</p>
```
