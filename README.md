# Русификатор PC Store Together

Русский язык для **PC Store Together** на Windows. Версия **v1.1.1** поддерживает Steam-сборку **26903133** и совместимые более новые сборки. Новые строки без перевода будут отображаться на английском.

Переведены все **4 060 строк** штатной таблицы, включая меню, обучение, мастерскую и DreamOS. Дополнительно переведены подсказка поиска деталей и подпись пользовательского плейлиста.

[Релизы на GitHub](https://github.com/sanossan/PC-Store-Together-RUS/releases). У каждого выпуска указаны поддерживаемая Steam-сборка, установщик EXE, архив ZIP и контрольные суммы SHA-256.

## Установка через EXE

1. Закройте игру и запустите скачанный файл `PC-TOGETHER-RUS-v…-Setup.exe`.
2. Проверьте предложенную папку игры и нажмите **Установить**. Чтобы указать другую папку, нажмите **Обзор** и выберите каталог с файлом `PC Store Simulator Together.exe`.
3. Запустите игру через Steam и выберите **Русский** в **Settings → Language**.

На сборке 26903133 установщик сверяет SHA-256 игровых файлов. На более новой сборке он определяет Build ID по манифесту Steam в той же библиотеке и проверяет структуру таблицы локализации и игровые методы. При несовместимости установка остановится. Автономная копия игры без манифеста поддерживается по контрольным суммам сборки 26903133. EXE выпущен без цифровой подписи.

## Обновление русификатора

На сборке **26903133** установите v1.1.1 поверх v1.1.0 через EXE или ZIP. Если игра использует более старую сборку, сначала обновите её в Steam. Если после обновления игры установщик сообщает о несовпадении файлов или обнаруживает перевод от прежней сборки, запустите в Steam проверку целостности и повторите установку.

## Восстановление оригинальных файлов

Закройте игру, запустите тот же EXE и нажмите **Восстановить оригинал**. Установщик вернёт игровые файлы из резервных копий с суффиксом `.pc-together-rus-original.<Steam Build ID>`. Для сборок новее базовой сохраните вместе с копиями файл `.pc-together-rus.<Steam Build ID>.json` в папке `PC Store Simulator Together_Data`. Для базовой сборки установщик также распознаёт исправные копии с прежним суффиксом `.pc-together-rus-original`.

## Установка из ZIP

Закройте игру, распакуйте архив и откройте Windows PowerShell в распакованной папке. Замените путь в первой строке на свой. Папку игры можно открыть из Steam через **Свойства → Установленные файлы → Обзор**. Если Windows отказывает в записи в `Program Files`, запустите PowerShell от имени администратора.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game
```

После установки выберите **Русский** в настройках языка игры. Чтобы восстановить оригинальные файлы, закройте игру и добавьте `-Action Restore` к команде установки.

## Перевод и проверка

Для v1.1.1 проверили установку и восстановление через EXE и ZIP на копиях Steam-сборок **26903133** и **26919223**. Переключение на русский и сохранение выбора после перезапуска проверяли в игре на сборке 26903133 с v1.1.0. Тестирование кооператива не проводилось.

## Сборка релиза

Укажите версию и целевую Steam-сборку в `release.json`. При обновлении для той же сборки добавьте в `previousPatches` номер и обе контрольные суммы прошлого релиза, сохранив существующую историю. Для новой Steam-сборки адаптируйте код патча под её оригинальные файлы и начните историю со списка `[]`.

Из корня репозитория запустите команду с путём к копии поддерживаемой сборки с оригинальными файлами.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\Build-Release.ps1 -GamePath 'D:\GameCopy'
```

Команда обновит хеши патча в манифесте и соберёт в `dist` установщик, ZIP и контрольные суммы. В описании выпуска на GitHub укажите Steam Build ID, изменения перевода и порядок обновления.

Установщик собирает патч из локальных файлов игры. В EXE и ZIP входит библиотека Mono.Cecil 0.11.6. [Mono.Cecil и лицензия MIT](https://github.com/jbevain/cecil/tree/0.11.6)
