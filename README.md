# Русификатор PC Store Together

Версия **1.0.0** для Windows и Steam-сборки **26897952**. Русский язык появляется в штатных настройках игры. Переведены все **4 044 записи** английской таблицы и подключены к переводу подсказка поиска деталей и подпись пользовательского плейлиста DreamOS.

## Установка

1. Закройте игру и скачайте [установщик для Windows](https://github.com/sanossan/PC-TOGETHER-RUS/releases/download/v1.0.0/PC-TOGETHER-RUS-v1.0.0-Setup.exe).
2. Запустите EXE. Проверьте предложенную папку Steam или выберите её через **Обзор**. Нажмите **Установить**.
3. Запустите игру из Steam. Откройте **Settings → Language** и выберите **Русский**.

### Установка из ZIP

1. Закройте игру. Скачайте `PC-TOGETHER-RUS-v1.0.0.zip` со [страницы релиза](https://github.com/sanossan/PC-TOGETHER-RUS/releases/tag/v1.0.0) и распакуйте архив.
2. В Steam откройте свойства игры, выберите «Установленные файлы» → «Обзор» и скопируйте путь к папке. В ней должен быть `PC Store Simulator Together.exe`.
3. Откройте PowerShell в распакованной папке. В команде укажите свой путь к игре. Если папка находится в `Program Files` и Windows отказывает в записи, откройте PowerShell от имени администратора.

```powershell
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath 'D:\SteamLibrary\steamapps\common\PC Store SIm'
```

4. Запустите игру из Steam. Откройте **Settings → Language** и выберите **Русский** в списке языков.

Установщик проверяет SHA-256 двух исходных файлов и создаёт рядом с ними резервные копии с суффиксом `.pc-together-rus-original`. После обновления игры в Steam проверьте номер сборки.

## Восстановление

Закройте игру, запустите EXE и нажмите **Восстановить оригинал**. Резервные копии сохранятся. Если вы используете версию из ZIP, выполните команду с тем же путём.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath 'D:\SteamLibrary\steamapps\common\PC Store SIm' -Action Restore
```

## Что проверено

- Установщик EXE и скрипт для Windows PowerShell 5.1 проверены на временных копиях файлов игры. Проверены установка, повторная установка, восстановление, возобновление прерванной установки и отказ при несовместимой сборке.
- Сверены ключи, параметры подстановки, форматирование и ссылки в каталоге Unity. Исходные записи английской таблицы и остальные языки сохранены.
- В отдельном запуске через журнал Unity проверены переключение на русский, сохранение выбора после перезапуска с отдельной тестовой настройкой, подстановка в динамическом сообщении и доступность 66 русских букв в TextMesh Pro, включая Ё и ё. Визуальная проверка экранов и кооператив остались без тестирования.
- Перевод создан локально с Argos Translate и отредактирован при помощи Codex. Меню, настройки, обучение, названия моделей и тексты главного экрана DreamOS вычитаны отдельно. В остальном тексте возможны неточности. Озвучка, пользовательские строки и интерфейс Steam вне охвата.

Установщик собирает патч из файлов вашей игры. В EXE и архив включена библиотека Mono.Cecil 0.11.6. [Mono.Cecil и лицензия MIT](https://github.com/jbevain/cecil/tree/0.11.6)
