# Русификатор PC Store Together

Русификатор **v1.2.1** для **PC Store Together** на Windows поддерживает игру версии **v0.1.5** (базовая Steam-сборка **26919223**). Более новые Steam-сборки поддерживаются, если игровые файлы проходят проверку совместимости перед заменой. Новые строки без перевода и изменённые строки, для которых прежний перевод больше не подходит, отображаются на английском.

В базовой сборке переведены все **4 069 строк** штатной таблицы, включая меню, обучение, мастерскую, DreamOS и подсказку поиска деталей. Отдельно добавлен перевод подписи пользовательского плейлиста.

[Релизы на GitHub](https://github.com/sanossan/PC-Store-Together-RUS/releases). Здесь доступны установщик EXE, архив ZIP и контрольные суммы SHA-256.

## Установка через EXE

1. Закройте игру и запустите скачанный файл `PC-TOGETHER-RUS-v…-Setup.exe`.
2. Проверьте предложенную папку игры и нажмите **Установить**. Чтобы указать другую папку, нажмите **Обзор** и выберите каталог с файлом `PC Store Simulator Together.exe`.
3. Запустите игру через Steam и выберите **Русский** в **Settings → Language**.

## Установка из ZIP

Закройте игру, распакуйте архив и откройте Windows PowerShell в распакованной папке. Замените путь в первой строке на свой. Папку игры можно открыть из Steam через **Свойства → Установленные файлы → Обзор**. Если Windows отказывает в записи в `Program Files`, запустите PowerShell от имени администратора.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game
```

После установки запустите игру через Steam и выберите **Русский** в **Settings → Language**.

## Как обновить русификатор

Для игры версии **v0.1.5** (Steam-сборка **26919223**) можно установить **v1.2.1** поверх **v1.2.0**, **v1.1.2** или **v1.1.1**, если резервные копии оригиналов сохранились и проходят проверку. Закройте игру и установите новую версию по инструкции для EXE или ZIP выше.

## Восстановление оригинальных файлов

Закройте игру. Для восстановления через EXE запустите установщик и нажмите **Восстановить оригинал**.

Для восстановления из ZIP откройте Windows PowerShell в распакованной папке и выполните команды, указав свой путь к игре.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game -Action Restore
```

Установщик восстанавливает игровые файлы из резервных копий с суффиксом `.pc-together-rus-original.<Steam Build ID>`. Для сборок новее базовой сохраните вместе с копиями файл `.pc-together-rus.<Steam Build ID>.json` в папке `PC Store Simulator Together_Data`. Для базовой сборки установщик также распознаёт исправные копии с прежним суффиксом `.pc-together-rus-original`.

Если резервные копии или запись об установке потеряны либо повреждены, восстановите игровые файлы через Steam. В свойствах игры откройте **Установленные файлы → Проверить целостность файлов игры**. [Инструкция Steam](https://help.steampowered.com/ru/faqs/view/0C48-FCBD-DA71-93EB)

## Сборка релиза

Укажите версию и целевую Steam-сборку в `release.json`. В `previousPatches` храните номера выпусков и контрольные суммы их патчей для целевой сборки. Если новый базовый Build ID уже поддерживался в режиме совместимости, добавьте проверенные хеши патчей, полученные на этой сборке.

Из корня репозитория запустите команду с путём к копии поддерживаемой сборки с оригинальными файлами.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\Build-Release.ps1 -GamePath 'D:\GameCopy'
```

Команда обновит хеши патча в манифесте и соберёт в `dist` установщик, ZIP и контрольные суммы. В описании выпуска на GitHub укажите поддерживаемую версию игры, изменения перевода и порядок обновления. Версию игры возьмите из поля `PlayerSettings.bundleVersion` в файле `PC Store Simulator Together_Data/globalgamemanagers` целевой сборки.

Установщик собирает патч из локальных файлов игры. В EXE и ZIP входит библиотека Mono.Cecil 0.11.6. [Mono.Cecil и лицензия MIT](https://github.com/jbevain/cecil/tree/0.11.6)
