# Русификатор PC Store Together

Русификатор **v1.3.1** для **PC Store Together** на Windows поддерживает игру версии **v0.1.6** (базовая Steam-сборка **26927316**). Более новые Steam-сборки поддерживаются, если игровые файлы проходят проверку совместимости перед заменой. Новые строки без перевода и строки с несовместимыми параметрами подстановки или тегами отображаются на английском.

В базовой сборке переведены все **4 072 строки** штатной таблицы, включая меню, обучение, мастерскую, DreamOS и подсказку поиска деталей. Отдельно добавлен перевод подписи пользовательского плейлиста.

[Релизы на GitHub](https://github.com/sanossan/PC-Store-Together-RUS/releases). Здесь доступны установщик EXE, архив ZIP и контрольные суммы SHA-256.

## Установка через EXE

1. Закройте игру и запустите скачанный файл `PC-TOGETHER-RUS-v…-Setup.exe`.
2. Проверьте предложенную папку игры. Чтобы указать другую папку, нажмите **Обзор** и выберите каталог с файлом `PC Store Simulator Together.exe`.
3. Для установки без копии снимите флажок **Создать резервную копию оригинальных файлов**. Нажмите **Установить**.
4. Запустите игру через Steam и выберите **Русский** в **Settings → Language**.

На базовой Steam-сборке для установки потребуется около 3,1 ГБ свободного места на диске с игрой при создании резервной копии или около 1,6 ГБ без неё. После установки временные файлы удаляются. Ранее созданные копии сохраняются.

## Установка из ZIP

Закройте игру, распакуйте архив и откройте Windows PowerShell в распакованной папке. Замените путь в первой строке на свой. Папку игры можно открыть из Steam через **Свойства → Установленные файлы → Обзор**. Если Windows отказывает в записи в `Program Files`, запустите PowerShell от имени администратора.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game
```

Для установки без резервной копии добавьте `-NoBackup` в конец последней команды.

После установки запустите игру через Steam и выберите **Русский** в **Settings → Language**.

## Как обновить русификатор

Закройте игру. Если у вас уже установлена **v0.1.6** или более новая совместимая версия игры, установите **v1.3.1** через EXE или ZIP. С более ранней версией игры сначала обновитесь через Steam.

Если для обновления русификатора установщику нужны оригинальные файлы и резервных копий нет, проверьте целостность файлов игры через Steam и повторите установку.

## Восстановление оригинальных файлов

Закройте игру. Для восстановления через EXE запустите установщик и нажмите **Восстановить оригинал**.

Для восстановления из ZIP откройте Windows PowerShell в распакованной папке и выполните команды, указав свой путь к игре.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game -Action Restore
```

Установщик восстанавливает `data.unity3d` и `Assembly-CSharp.dll` из резервных копий с суффиксом `.pc-together-rus-original.<Steam Build ID>`. Для сборок новее базовой сохраните вместе с копиями файл `.pc-together-rus.<Steam Build ID>.json` в папке `PC Store Simulator Together_Data`.

Если вы установили русификатор без резервных копий или копии либо запись об установке потеряны или повреждены, восстановите игровые файлы через Steam. В свойствах игры откройте **Установленные файлы → Проверить целостность файлов игры**. [Инструкция Steam](https://help.steampowered.com/ru/faqs/view/0C48-FCBD-DA71-93EB)

## Сборка релиза

Укажите версию русификатора, версию игры (`gameVersion`) и целевую Steam-сборку в `release.json`. В `previousPatches` храните номера выпусков и контрольные суммы их патчей для целевой сборки. Если новый базовый Build ID уже поддерживался в режиме совместимости, добавьте проверенные хеши патчей, полученные на этой сборке.

Из корня репозитория запустите команду с путём к копии поддерживаемой сборки с оригинальными файлами.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\Build-Release.ps1 -GamePath 'D:\GameCopy'
```

Команда обновит хеши патча в манифесте и соберёт в `dist` установщик, ZIP и контрольные суммы. В описании выпуска на GitHub укажите поддерживаемую версию игры, изменения перевода и порядок обновления. Версию игры возьмите из поля `PlayerSettings.bundleVersion` в ресурсе `globalgamemanagers` из архива `PC Store Simulator Together_Data/data.unity3d` целевой сборки.

Установщик собирает патч из локальных файлов игры. В EXE и ZIP входит библиотека Mono.Cecil 0.11.6. [Mono.Cecil и лицензия MIT](https://github.com/jbevain/cecil/tree/0.11.6)
