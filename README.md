# Русификатор PC Store Together

Русский язык для **PC Store Together** на Windows. Русификатор **v1.0.0** поддерживает Steam-сборку **26897952**.

Переведены все **4 044 строки** штатной таблицы, включая меню, обучение, мастерскую и DreamOS. Дополнительно переведены подсказка поиска деталей и подпись пользовательского плейлиста.

## Установка через EXE

1. Закройте игру и запустите `PC-TOGETHER-RUS-v1.0.0-Setup.exe`.
2. Проверьте предложенную папку игры и нажмите **Установить**. Чтобы указать другую папку, нажмите **Обзор** и выберите каталог с файлом `PC Store Simulator Together.exe`.
3. Запустите игру через Steam и выберите **Русский** в **Settings → Language**.

Установщик проверяет контрольные суммы игровых файлов и создаёт резервные копии с суффиксом `.pc-together-rus-original`. Если файлы отличаются от поддерживаемой сборки, установка остановится. EXE выпущен без цифровой подписи.

## Восстановление оригинальных файлов

Закройте игру, запустите тот же EXE и нажмите **Восстановить оригинал**. Установщик вернёт игровые файлы из резервных копий и сохранит сами копии.

## Установка из ZIP

Закройте игру, распакуйте архив и откройте Windows PowerShell в распакованной папке. Замените путь в первой строке на свой. Папку игры можно открыть из Steam через **Свойства → Установленные файлы → Обзор**. Если Windows отказывает в записи в `Program Files`, запустите PowerShell от имени администратора.

```powershell
$game = 'D:\SteamLibrary\steamapps\common\PC Store SIm'
Unblock-File -LiteralPath '.\Install-Russian.ps1', '.\lib\Mono.Cecil.dll'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Install-Russian.ps1' -GamePath $game
```

После установки выберите **Русский** в настройках языка игры. Чтобы восстановить оригинальные файлы, закройте игру и добавьте `-Action Restore` к команде установки.

## Перевод и проверка

- EXE и PowerShell-скрипт проверены на временных копиях игры. Проверка охватила установку, повторную установку, восстановление, продолжение прерванной установки и отказ при несовместимой сборке.
- Сверены ключи, параметры подстановки и форматирование текстов Unity. По журналу игры проверены переключение языка, сохранение выбора после перезапуска с отдельной тестовой настройкой, подстановка в динамическом сообщении и доступность кириллицы, включая **Ё/ё**. Визуальная проверка экранов и кооператив остались без тестирования.
- Перевод подготовлен локально с Argos Translate и отредактирован при помощи Codex. Отдельно вычитаны меню, настройки, обучение, названия моделей и главный экран DreamOS. В остальных текстах возможны неточности. Озвучка, пользовательский ввод и интерфейс Steam вне охвата.

Установщик собирает патч из локальных файлов игры. В EXE и ZIP входит библиотека Mono.Cecil 0.11.6. [Mono.Cecil и лицензия MIT](https://github.com/jbevain/cecil/tree/0.11.6)
