# Карта проекта PC Store Together RUS

Найди свою задачу в таблице и открой указанные файлы. Для поиска конкретной фразы или ключа перевода начни с `rg -n -F -- 'фраза или ключ' ru.json`.

| Задача | Где искать |
| --- | --- |
| Исправить перевод меню, обучения, мастерской или DreamOS | [`ru.json`](ru.json) содержит пары `key` и `value`. При правке текста сохраняй ключи, параметры подстановки и теги Unity. |
| Проверить полноту перевода, подстановки и теги или изменить добавление языка Ru | [`PcStoreLocale.cs`](PcStoreLocale.cs) проверяет словарь и собирает патч Unity-ресурса `sharedassets1.assets`. Здесь же находятся имя ресурса, число штатных строк и SHA-256 оригинальных игровых файлов. |
| Разобраться с подсказкой поиска деталей или подписью пользовательского плейлиста | [`PcStoreLabels.cs`](PcStoreLabels.cs) перенаправляет вывод этих двух строк на локализацию через патч `Managed/Assembly-CSharp.dll`. Тексты находятся в [`ru.json`](ru.json). |
| Изменить окно EXE или поиск папки игры в Steam | [`installer/Setup.cs`](installer/Setup.cs) содержит интерфейс WinForms, обработчики кнопок и поиск папки игры. |
| Изменить запуск установщика из ZIP | [`Install-Russian.ps1`](Install-Russian.ps1) принимает путь к игре и действие `Install` или `Restore`, загружает зависимости и вызывает общую логику установки. |
| Разобраться с отказом по хешам, обновлением или восстановлением | [`installer/InstallTransaction.cs`](installer/InstallTransaction.cs) обслуживает оба установщика. Здесь проверяются манифест и файлы игры, обрабатываются резервные копии, установка и восстановление. |
| Проверить версию, Steam Build ID или хеши прежних патчей | [`release.json`](release.json) содержит версию, идентификаторы Steam, хеши патча и историю `previousPatches` для целевой сборки. |
| Собрать выпуск или разобраться, что входит в пакеты | [`installer/Build-Release.ps1`](installer/Build-Release.ps1) собирает EXE, ZIP и файлы `.sha256` из копии игры с оригиналами. [`installer/Build-Exe.ps1`](installer/Build-Exe.ps1) компилирует EXE и встраивает ресурсы. Зависимость Mono.Cecil и её лицензия лежат в [`lib/`](lib/). |
| Найти инструкции для игроков, сведения о проверках или правила публикации | [`README.md`](README.md) описывает установку, обновление, восстановление и сборку. [`AGENTS.md`](AGENTS.md) задаёт правила версий и публикации. |

## Локальные папки

- `dist/` содержит собранные EXE, ZIP и файлы `.sha256` по версиям. Найти нужный комплект можно по версии из `release.json`.
- `.work/` содержит временные материалы. Для поиска английского оригинала по ключу начни с `.work/source.json`, если файл есть. Сценарий `.work/check-release-upgrade.py` проверяет переход с v1.0.0 через EXE и ZIP на тестовых копиях, используя `.work/fixture/` и `dist/`.
- Обе папки исключены из Git через [`.gitignore`](.gitignore). Для обычных правок начни с таблицы выше, а локальные материалы открывай по необходимости.
